## 4. My understanding
### Task 1.1 - Typing and saving a document

| Stage | What happens | Component |
|---|---|---|
| Input | Pressing keys supplies characters. | Keyboard |
| Processing | The editor handles keystrokes, updates the document and arranges characters on the page. | CPU and RAM |
| Output | The current document appears on the display. | Screen |
| Storage | Saving writes the document to a file so it can be opened later. | SSD |

Keystrokes become data that the program processes in memory. The screen shows the current result, and saving stores a persistent copy. Unsaved changes in RAM can be lost when the program closes or power fails.

### Task 1.3 - Everyday computer-based systems

| System | Main purpose | Input | Output |
|---|---|---|---|
| ATM | Provide banking services | Card and keypad choices | Cash or transaction message |
| Traffic signal controller | Coordinate traffic movements | Vehicle sensor signal | Changed signal lights |
| Ticket machine | Issue travel tickets | Destination selection | Ticket and price display |

Hardware is the physical equipment. Software gives that equipment instructions. The operating system coordinates resources so applications can use them.
